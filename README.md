## 📖 English

**No More Other: Github Languages** is a lightweight userscript (for [Violentmonkey](https://violentmonkey.github.io/) / [Tampermonkey](https://www.tampermonkey.net/)) that fixes GitHub's language statistics. It reveals languages buried under the "Other" category, displaying them with precise percentages (down to `< 0.01%`) and stable, unique colors.

### ✨ Features

*   **Reveals Hidden Languages:** No more mysterious grey "Other" bars. See exactly what languages your project uses.
*   **Precise Percentages:** Displays exact numbers (e.g., `0.05%`), and uses `< 0.01%` for the tiniest fragments so nothing gets lost.
*   **Deterministic Colors:** Generates beautiful, unique HSL colors based on the language name.
*   **Seamless Integration:** Works perfectly with GitHub's SPA navigation. Just click on any repo, and it updates instantly.

### 🚀 Installation

1.  Install a userscript manager for your browser:
    *   [Violentmonkey](https://violentmonkey.github.io/) (Recommended for Chrome/Firefox)
    *   [Tampermonkey](https://www.tampermonkey.net/) (Classic choice)
2.  **[Click here to install the script](https://raw.githubusercontent.com/Asderekl/No-More-Other-GitHub-Languages/main/no-more-other.user.js)**. Confirm the installation in the userscript manager popup.
4.  Open any repository on GitHub and refresh the page.

## 📖 Русский

**No More Other: Github Languages** — это легкий пользовательский скрипт (для [Violentmonkey](https://violentmonkey.github.io/) / [Tampermonkey](https://www.tampermonkey.net/)), который исправляет статистику языков на GitHub. Он раскрывает языки, скрытые в категории «Other», отображая их с точными процентами (вплоть до `< 0.01%`) и стабильными уникальными цветами.

### ✨ Особенности

*   **Раскрывает скрытые языки:** Больше никаких загадочных серых полос «Other». Вы видите, на каких языках на самом деле написан ваш проект.
*   **Точные проценты:** Отображает точные цифры (например, `0.05%`), а для мельчайших фрагментов использует `< 0.01%`, чтобы ничего не терялось.
*   **Стабильные цвета:** Генерирует красивые уникальные цвета HSL на основе названия языка.
*   **Бесшовная интеграция:** Идеально работает с навигацией GitHub SPA. Просто кликните на любой репозиторий, и статистика обновится мгновенно.

### 🚀 Установка

1.  Установите менеджер скриптов для вашего браузера:
    *   [Violentmonkey](https://violentmonkey.github.io/) (Рекомендуется для Chrome/Firefox)
    *   [Tampermonkey](https://www.tampermonkey.net/) (Классический выбор)
2.  **[Нажмите сюда, чтобы установить скрипт](https://raw.githubusercontent.com/Asderekl/No-More-Other-GitHub-Languages/main/no-more-other.user.js)**
3.  Подтвердите установку во всплывающем окне менеджера скриптов.
4.  Откройте любой репозиторий на GitHub и обновите страницу.
